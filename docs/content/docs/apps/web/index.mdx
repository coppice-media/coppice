title: Web Apps
description: Coppice Home and Editor browser applications
---

Coppice's browser experience is provided by two independently built static
SvelteKit applications: Home and Editor.

## Home

Home is the user-facing app at `/app`. It provides library browsing, reading,
devices, account, and request workflows. See the [Home app developer guide](/docs/developer/home-app)
for its routes, deployment configuration, and shared UI.

## Editor

Editor is the ingest app at `/editor`. It provides the drop, queue, rework,
bulk, and library workflows. See the [ingest editor guide](/docs/developer/modular-ingest)
for its workflow and API boundaries.

## Deployment

The server serves each build when its directory is configured with
`STUMP_HOME_APP_DIR` or `INGEST_EDITOR_DIR`. The full Docker target builds and
configures both; custom deployments may build the apps independently. See
[modular deployment](/docs/guides/configuration/modular-deployment).
