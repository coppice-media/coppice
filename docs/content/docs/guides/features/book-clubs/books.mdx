There are two types of books that can be added to a book club schedule:

1. **Internal books**: These are books that exist in the Coppice library
2. **External books**: These are books that do not exist in the Coppice library, but can still be added to a book club via manual entry of the book's details (title, author, and optionally a cover image URL)

## Book queue and scheduling

Home **Social** lets club admins add and reorder books and mark the current
book complete. There is no due-date/reminder scheduler. A guest-reader session
can publish the current queued **library** book, or advance to the next queued
library book in one step. External/manual books can be on the club queue, but
cannot be published for accountless reading; see
[Guest reading links](/docs/guides/features/book-clubs/guest-reader).

## Suggestions and Voting

The server exposes GraphQL operations for members to suggest an existing
visible library book or an external title/author, like a suggestion, and
for admins to accept or reject it
(`crates/graphql/src/mutation/book_club_suggestion.rs`). Home **Social**
does not yet have suggestion/voting controls. Unlike the guest session's
private discussion, these operations belong to managed book-club members.

## Future Improvements

Some features that I think would be nice to have:

- Loose scheduling features, such as the ability to set a target date for finishing a book and some basic reminders around that
- Automation around suggestions based on upvotes, such as the ability for club admins to configure a setting that will automatically make the most upvoted suggestion the current book once the current book is archived
