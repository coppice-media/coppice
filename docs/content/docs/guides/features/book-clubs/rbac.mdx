These user permissions affect access to the book club feature as a whole:

    1. Any managed account with the `ACCESS_BOOK_CLUB` permission may access the book club feature. This means that they can view and join book clubs
    2. Any managed account with the `CREATE_BOOK_CLUB` permission may create book clubs (and therefore inherently has the `ACCESS_BOOK_CLUB` permission)
    3. `SHARE_BOOK_CLUB_READER` lets a club Admin or Creator issue [guest reading links](/docs/guides/features/book-clubs/guest-reader) to people without accounts. It is opt-in and also implies `ACCESS_BOOK_CLUB`

The server owner, or a user with `MANAGE_USERS`, assigns these on the Home app's **Users** screen (`/app/users`), where the *Book clubs and smart lists* group shows `ACCESS_BOOK_CLUB` as included once `CREATE_BOOK_CLUB` or `SHARE_BOOK_CLUB_READER` is ticked. [OIDC group mapping](/docs/guides/access-control/oidc) can assign them too, and while OIDC permission sync is on it replaces an OIDC account's permissions at every sign-in. For the full list, see the [user permissions](/docs/guides/access-control/permissions) guide.

## Club Visibility

A club can be public or private. Public clubs are visible to managed users with book-club access, who can join; private clubs are visible to their members, and an Admin or Creator must invite a user to join (`crates/graphql/src/mutation/book_club_invitation.rs::validate_book_club_invitation_input`). The server owner is not bound by those visibility restrictions. Guest-reader links are separate and do not make their holders club members.

## Club Roles

Within a book club, there are 4 roles:

| Role          | Permissions                                                                                |
| ------------- | ------------------------------------------------------------------------------------------ |
| **Creator**   | Full control over the book club, including deleting it at any time                         |
| **Admin**     | Almost all of the same permissions as the creator, except they cannot delete the book club |
| **Moderator** | Management permissions over club discussions and membership                                |
| **Member**    | No special permissions within the book club                                                |

The server owner retains all of the permissions as a creator of any book club that exists on the server.

### Customizing Roles

Book clubs can create custom names for each of the four available roles. This was added to better support book clubs that want some themed and/or immersive names for their roles. For example, a book club that wants to take on a D&D-inspired theme might use names like these:

| Internal Role | Custom Name    |
| ------------- | -------------- |
| Creator       | Dungeon Master |
| Admin         | Adventurer     |
| Moderator     | Explorer       |
| Member        | Novice         |

Internally, nothing changes, but the names are displayed in the UI accordingly.

## Permissions

The following table outlines some examples of what each role can do within a book club. This is not an exhaustive list, but over time hopefully it becomes more complete:

| Permission                 | Example                             | Creator | Admin | Moderator | Member | Notes                                 |
| -------------------------- | ----------------------------------- | ------- | ----- | --------- | ------ | ------------------------------------- |
| Manage club settings       | Rename club, change settings        | ✅      | ✅    |           |        |                                       |
| Manage books               | Mark book as reading for club       | ✅      | ✅    |           |        |                                       |
| Manage discussions         | Delete an inappropriate message     | ✅      | ✅    | ✅        |        | Members can delete their own messages |
| Suggest books              | Suggest a book for the club         | ✅      | ✅    | ✅        | ✅     |                                       |
| Participate in discussions | Chat in the club's discussion rooms | ✅      | ✅    | ✅        | ✅     |                                       |
