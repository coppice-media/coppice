<Callout type="info" title="Current scope">
	Book clubs and the accountless [guest reader](/docs/guides/features/book-clubs/guest-reader)
	are implemented. The Home **Social** screen offers club membership, invites, a book queue, and
	guest sessions. Some older member-room discussion and book-suggestion operations exist only
	in GraphQL, without corresponding Home controls. This distinction is not a device-test claim.
</Callout>

<Callout title="Permission required">
	This functionality is gated behind the `ACCESS_BOOK_CLUB` user permission. To learn more about
	permissions, see the [Permissions](/docs/guides/access-control/permissions) guide.
</Callout>

Coppice can host book clubs for managed accounts and issue opt-in guest reading links for people without accounts. Use **Social** in the Home app (`/app/social`) to manage clubs and their book queues. See [Roles and permissions](/docs/guides/features/book-clubs/rbac) for member access and [Guest reading links](/docs/guides/features/book-clubs/guest-reader) for reader sessions.

## Basic requirements

To set up a book club in Coppice, you'll need:

- A Coppice instance
- A managed user account (otherwise, it would be a club of one)

You don't even technically need any books on the server to start a book club, either, since you can create book club schedules with 'external' books.

## How it works

Book clubs in Coppice are effectively just a group of users that all have access to special pages and functionalities that are only available to members of a given book club. There can be multiple book clubs in a single Coppice instance, and users can be members of multiple book clubs.

People without an account can join the reading itself through personal [guest reading links](/docs/guides/features/book-clubs/guest-reader). They read the club's current book in the browser and can share progress, highlights, and notes with the session, but they do not become club members.

Club suggestions, votes, and member-room discussion are available through
server GraphQL operations but have no Home controls yet; the guest session's
own discussion is available in the Home/guest reader. For feature requests,
use [this fork's issue tracker](https://github.com/coppice-media/coppice/issues)
rather than the upstream Stump issue linked in older versions of this page.
