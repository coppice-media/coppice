---
title: Thumbnails
---

Coppice uses thumbnails to display images of your media throughout the app. By default, Coppice takes the first image from a media file, shrinks it to fit within 400×600 pixels as WebP the first time anyone asks for it, and keeps that file. You can customize the size and format per-library by configuring the thumbnail generation settings.

## Thumbnail Generation

The generation of thumbnails is controlled by the configuration options for a library. These options include:

- Explicitly sizing each thumbnail (height and width in pixels)
- Scaling both dimensions of each thumbnail by a factor (e.g., 0.5)
- The format to encode the thumbnail in (e.g., JPEG, PNG, WebP)
- The quality of the encoding (1–100; unset means 100)

Thumbnail generation is optional. Without it, a library's thumbnails are still bounded images (400×600 WebP at quality 80) made from the first page on first request rather than the raw page; configuring it lets you pick the size, format and quality, and have a job generate every thumbnail ahead of time instead of on first request.

Please note that when thumbnail generation is enabled, you may not opt out of [placeholder color processing](#thumbnail-placeholder-colors), as the two features are somewhat intertwined.

<Callout type="info" title="Performance Note">
	A first page Coppice cannot re-encode (an image type its encoder does not read, such as AVIF or
	JPEG XL) is served as-is, which can be very large and slow to load. Configuring thumbnail
	generation does not change that; it only changes the size and format of the thumbnails that
	can be encoded.
</Callout>

### Image Candidacy

When generating thumbnails, Coppice will use the very first image it encounters in the media file as the thumbnail.

## Supported Formats

### Generation

Coppice supports generating thumbnails to and from the following formats:

- JPEG
- PNG
- WebP

You should ensure that your browser supports the format you plan to use. You can visit the following links to check:

- [WebP](https://caniuse.com/webp)

### Display

Coppice supports the following formats for displaying thumbnails, in addition to the above:

- [GIF](https://caniuse.com/gif)

The reason for this separation is that while Coppice supports rendering these on the UI, there is no process to convert them.

## Thumbnail Placeholder Colors

Clients that support progressive thumbnail loading can show a placeholder based on a thumbnail's dominant colors before displaying the full image.

If you enable this feature, Coppice computes the dominant colors during thumbnail generation so compatible clients can use them while the image loads. Three placeholder styles are available:

- Average Color: A single color placeholder based on the average color of the thumbnail image
- Colorful: A tvOS-like placeholder using multiple dominant colors from the thumbnail image
- Thumbhash: A low-resolution placeholder generated using the [Thumbhash](https://evanw.github.io/thumbhash/) algorithm

If you choose to disable this feature, a default gray placeholder will be used instead.

## Management

Thumbnail management can be done in either the settings page associated with a particular entity or in the settings page for the library as a whole. For example:

- `/books/{bookId}/manage`
- `/series/{seriesId}/settings`
- `/libraries/{libraryId}/settings`

### Thumbnail Selection

You have the option to manually select an image as a thumbnail. This is useful when either the automatic selection is incorrect or when you want to use a special image. The selection is done on a media file, so if you are selecting for a:

- `Library`: You will select a particular series, then a particular book, then a particular page
- `Series`: You will select a particular book, then a particular page
- `Book`: You will select a particular page

You may also upload a custom image to use as a thumbnail.

### Regeneration

You have the ability to regenerate thumbnails in a given library's settings page. The options are:

- Generate only missing thumbnails — a thumbnail that was made on first request in the same format counts as present, so it keeps its size until forced
- Force regenerate all thumbnails

### Deletion

You can delete a thumbnail in a given library's settings page. This will remove all thumbnails associated with the library and its entities.
