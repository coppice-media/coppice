## Download the source code

You can download the source code for Stump from the [GitHub repository](https://github.com/stumpapp/stump). You can either clone the repository using Git or download it as a ZIP file and extract it.

### Dedicated release channels

If you want the latest release, the `main` branch is the best option. Commits are usually only made to `main` through the release pipeline. You may also want to check out the `nightly` branch, where you can get access to some of the more cutting edge features that are still in development.

Any other branch is likely to be unstable and not recommended for installation.

## Install dependencies

The [contributing guide](/docs/developer/contributing) provides detailed instructions on installing the necessary dependencies for building Stump from source. Please follow those instructions to set up your development environment.

## Build Stump locally

Build the server and both static apps:

```bash copy
bun run home build && bun run editor build
cargo build --package stump_server --release
```

The server binary is located at `target/release/stump_server`. Configure
`STUMP_HOME_APP_DIR` and `INGEST_EDITOR_DIR` to the corresponding build
directories (`home/build` and `editor/build`) to serve `/app` and `/editor`.
See the [server configuration reference](/docs/guides/configuration/server-config) for details.

## Enable PDF support

PDF rendering relies on [PDFium](https://pdfium.googlesource.com/pdfium/). Unlike the Docker image, a source build does **not** include the PDFium binary, so you must download it yourself and tell Stump where it is. Without this, opening a PDF fails with a `PdfConfigurationError`.

1. Download the PDFium binary for your platform from [bblanchon/pdfium-binaries](https://github.com/bblanchon/pdfium-binaries/releases). Each release archive contains the shared library under `lib/`:

   - macOS: `libpdfium.dylib`
   - Linux: `libpdfium.so`
   - Windows: `pdfium.dll`

2. Point Stump at the binary via the `PDFIUM_PATH` environment variable (or the `pdfium_path` key in your `Stump.toml`):

   ```bash copy
   export PDFIUM_PATH="/absolute/path/to/libpdfium.dylib"
   ```

<Callout type="info">
  `PDFIUM_PATH` must be the full path to the library file itself, not the directory containing it. See the [server configuration reference](/docs/guides/configuration/server-config#pdfium_path) for more details.
</Callout>

### Arch Linux (AUR)

An [AUR package](https://aur.archlinux.org/packages/stump) is available for Arch-based Linux distributions. It compiles Stump from source and installs a systemd service for you. You can install it using your preferred AUR helper:

```bash copy
yay -S stump
```
