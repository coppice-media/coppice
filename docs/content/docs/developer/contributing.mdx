Coppice is developed in this repository. Use the repository issue tracker to
discuss bugs and substantial proposals before beginning broad changes. The
repository-level `.github/CONTRIBUTING.md` is the short contribution entrypoint
for contributors working from a checkout.

## Active workspaces

JavaScript tooling is Bun-only. The repository pins Bun 1.4.1 and has no Node.js
workspace or CI runtime.

| Workspace | Responsibility |
| --- | --- |
| `home/` | SvelteKit Home application, served at `/app`. |
| `editor/` | SvelteKit ingest Editor, served at `/editor`. |
| `packages/stump-ui/` | Shared Svelte UI and GraphQL operations. |
| `docs/` | Public Coppice documentation. |
| Rust workspace | Server, libraries, migrations, and protocol adapters. |

Install JavaScript dependencies from the repository root with
`bun install --frozen-lockfile`. Useful commands include:

```sh
bun run check-types
bun run home dev
bun run editor dev
bun run docs dev
bun run home build
bun run editor build
bun run docs build
```

Regenerate GraphQL types for each affected workspace:

```sh
bun run home codegen
bun run editor codegen
bun run --filter @stump/ui codegen
```

The server and crates use Cargo. Follow the package's existing verification
instructions and keep public protocol, auth, database, and mobile-client
contracts intact when changing server behavior.

## Documentation and compatibility evidence

Update the relevant public page when a behavior or supported configuration
changes. Keep implementation status distinct from evidence: an implemented
profile is not proof that every client works. The
[client verification matrix](/docs/developer/client-verification)
for pinned client versions and replay/device evidence; use the
[developer state](/docs/developer/state) and [roadmap](/docs/developer/roadmap) for implementation
boundaries and open work.

## Project identity and licensing

Coppice is derived from the open-source Stump project. Preserve Stump names when
they are compatibility identifiers such as package names, binaries, routes,
environment keys, storage fields, or upstream attribution; use Coppice as the
product name in user-facing prose. The repository is licensed under MIT; see
the root `LICENSE` for its copyright and terms.
